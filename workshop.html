2. Load the Data

Our simulation study examines statistical power and estimator performance using 27 state panels calibrated to Stanford Education Data Archive (SEDA) district achievement data. Pure-data and empirical-data simulations assess how sample size, outcome variability, serial correlation, and treatment design affect our ability to detect effects.

The planned lab adapts the pure-data approach using Texas’s parameters: 832 simulated districts over seven years, without adjustment covariates. These are generated outcomes, not actual Texas district records. The simulation manuscript is a working draft; a public link is not yet included.

Place the downloaded CSV files in your R project folder:

simple <- read_csv("simple_did_district.csv")
staggered <- read_csv("staggered_did_district.csv")

read_csv() comes from readr. Each row is one district in one year. We use outcome_raw, measured in illustrative score points. It equals 50 + 10 times outcome_std; a 0.20-SD effect equals 2 score points.

4. Estimate the Classic Two-by-Two DID

Use Year 4, immediately before adoption, and Year 5, the first treated year. Following the slides:

ATT̂2×2=(Y¯G,post−Y¯G,pre)−(Y¯C,post−Y¯C,pre) \widehat{\operatorname{ATT}}_{2\times2} =(\overline Y_{G,\mathrm{post}}-\overline Y_{G,\mathrm{pre}}) -(\overline Y_{C,\mathrm{post}}-\overline Y_{C,\mathrm{pre}})

GG is the treated group, CC the control group, and Y¯\overline Y a group mean. Under parallel trends and no anticipation, the control change supplies the untreated change for the treated group. Estimate the contrast using the slides’ TWFE equation:

Yit=αi+λt+βDit+uit Y_{it}=\alpha_i+\lambda_t+\beta D_{it}+u_{it} 
two_period <- simple %>%
  filter(year %in% c(4, 5))
model_2x2 <- feols(
  outcome_raw ~ treated | district_id + year,
  data = two_period,
  vcov = ~ district_id
)
summary(model_2x2)

5. Estimate TWFE Using All Seven Years

The equation stays the same:

Yit=αi+λt+βDit+uit Y_{it}=\alpha_i+\lambda_t+\beta D_{it}+u_{it} 
model_twfe <- feols(

  data = simple,
  vcov = ~ district_id
)
summary(model_twfe)
#> OLS estimation, Dep. Var.: outcome_raw
#> Observations: 1,120
#> Fixed-effects: district_id: 160,  year: 7
#> Standard-errors: Clustered (district_id)
#>         Estimate Std. Error t value   Pr(>|t|)
#> treated  2.28709   0.344651 6.63597 4.8105e-10 ***
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
#> RMSE: 1.83285     Adj. R2: 0.963675

Only data = simple changes: we now use all seven years. District effects account for persistent differences; year effects account for common shocks. In this balanced common-adoption design, the coefficient equals the treated group’s average pre-to-post change minus the control group’s average change. The true effect is 2 points in each post-treatment year. The time-constant treated_ever variable would be absorbed by district effects; use treated, which switches on at adoption.

6. Estimate an Event Study

Following the slides:

Yit=αi+λt+∑k≠−1βk𝟏{t−g=k}+uit Y_{it}=\alpha_i+\lambda_t+ \sum_{k\neq-1}\beta_k\,\mathbf{1}\{t-g=k\}+u_{it}

Here g=5g=5 and k=t−gk=t-g. The slides use shorthand: the event-time indicators apply to treated districts, not the never-treated comparison group. Our code makes this restriction explicit.

Study year Event time Interpretation
1, 2, 3 -4, -3, -2 Pre-treatment comparisons
4 -1 Reference period
5, 6, 7 0, 1, 2 First, second, third treated year 
simple <- simple %>%
  mutate(relative_year = year - 5)
model_event <- feols(
  outcome_raw ~ i(relative_year, treated_ever, ref = -1) |
    district_id + year,
  data = simple,
  vcov = ~ district_id
)
summary(model_event)

mutate() is from dplyr. This relative-year index is defined for every observation; the existing event_time is missing for never-treated districts. i() from fixest interacts relative-year indicators with treated_ever; ref = -1 omits Year 4.

Each βk\beta_k measures how the treated-control gap differs from its Year 4 value. Pre-treatment coefficients are diagnostics, not proof of parallel trends. Under parallel trends and no anticipation, post-treatment coefficients estimate effects relative to Year 4. Their true values are all 2 points here. Do not carry this common-adoption model mechanically into staggered adoption.

7. Move to Staggered Adoption

Effects now depend on cohort and year:

ATT⁡(g,t)=𝔼[Yit(g)−Yit(0)∣i∈Gg],t≥g \operatorname{ATT}(g,t)=\mathbb{E}[Y_{it}(g)-Y_{it}(0)\mid i\in G_g], \qquad t\geq g

GgG_g is the cohort first treated in gg; Yit(g)Y_{it}(g) is the potential outcome when treatment starts in gg; Yit(0)Y_{it}(0) is the outcome without treatment.

Cohort gg Year tt True effect (points)
5 5 1.00
5 6 2.00
5 7 3.00
6 6 1.50
6 7 2.50

These schedules apply to both the current and planned data. A single TWFE coefficient can mix never-treated, not-yet-treated, and already-treated comparisons. Already-treated controls can be problematic when effects change over time.

8. Estimate Cohort-Time Treatment Effects

Use att_gt() from did, implementing Callaway and Sant’Anna (2021). With never-treated controls:

ATT̂(g,t)=(Y¯g,t−Y¯g,g−1)−(Y¯C,t−Y¯C,g−1) \widehat{\operatorname{ATT}}(g,t) =(\overline Y_{g,t}-\overline Y_{g,g-1}) -(\overline Y_{C,t}-\overline Y_{C,g-1})

ATT(6,7) compares the Year 6 cohort’s change from Year 5 to Year 7 with the control group’s change over those same years.

set.seed(20261014)
model_csa <- att_gt(
  yname = "outcome_raw",
  tname = "year",
  idname = "district_id",
  gname = "treatment_start_year",
  xformla = ~ 1,
  data = staggered,
  panel = TRUE,
  control_group = "nevertreated",
  base_period = "universal",
  anticipation = 0,
  bstrap = TRUE,
  biters = 1000,
  clustervars = "district_id",
  cband = TRUE
)
summary(model_csa)

9. Read the Estimates and Uncertainty

Group identifies adoption cohort and Time identifies outcome year. Group 5 and Time 7 identify ATT(5,7), whose true value is 3 points. Pre-treatment comparisons are diagnostics, not effects of an already-active treatment.

bstrap = TRUE uses a multiplier bootstrap; biters = 1000 selects 1,000 iterations. clustervars = “district_id” allows within-district dependence over time. set.seed() makes the bootstrap reproducible in the same computing setup.

cband = TRUE requests simultaneous confidence bands across cohort-time estimates, rather than separate pointwise intervals. See the did inference options.

10. Aggregate the Cohort-Time Effects

Following the slides, the Simple ATT is:

ATT̂simple=∑g∑t=gTwg,tATT̂(g,t),wg,t=Ng∑hNh(T−h+1) \widehat{\operatorname{ATT}}_{\mathrm{simple}} =\sum_g\sum_{t=g}^{T}w_{g,t}\widehat{\operatorname{ATT}}(g,t), \qquad w_{g,t}=\frac{N_g}{\sum_h N_h(T-h+1)}

NgN_g is cohort size and T=7T=7 is the final year. This formula applies to our balanced panel without sampling weights. The treated cohorts have equal size, so each of the five cells receives weight 1/5. The true summary is:

ATT⁡simple=1.00+2.00+3.00+1.50+2.505=2.00 \operatorname{ATT}_{\mathrm{simple}} =\frac{1.00+2.00+3.00+1.50+2.50}{5}=2.00 
overall_csa <- aggte(model_csa, type = "simple")
summary(overall_csa)

aggte() from did takes the fitted model_csa object, not the original dataset. type = “simple” selects the aggregation rule. The early cohort contributes three post-treatment years and the late cohort two, giving total weights 3/5 and 2/5. Never-treated districts supply the comparison, but receive no treatment-effect weight. Do not average the five standard errors; the package accounts for joint uncertainty. See the aggte() documentation.
