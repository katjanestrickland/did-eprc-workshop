Hands-on R Lab

October 22, 2026 | 1:00-1:30 PM Eastern

This guided lab applies traditional and staggered DID methods to two simulated district-year datasets. We begin with a common treatment start, then examine districts adopting a gifted education program in different years. These are synthetic teaching examples, not the data or results of an actual gifted education study.

Download the complete R script · Download the R Markdown · Data and codebook

Allow 5 minutes for setup and data, 10 minutes for traditional DID, and 15 minutes for staggered DID and aggregation. The last two sections are optional follow-up.

1. Meet the Data

Each row represents one district in one study year. Both panels contain 160 districts observed for seven years (1,120 rows), with no adjustment covariates. Treatment stays on after adoption. Years 1-4 precede the earliest adoption.

The code first looks for local files, then uses the workshop downloads. To work offline, place the CSV files in your working folder or its data subfolder.

read_workshop_data <- function(filename) {
  candidates <- c(file.path("assets/data", filename), file.path("data", filename), filename)
  local <- candidates[file.exists(candidates)]
  source <- if (length(local)) local[1] else paste0(
    "https://katjanestrickland.github.io/did-eprc-workshop/assets/data/", filename)
  read_csv(source, show_col_types = FALSE)
}

treatment_start_year = 0 identifies never-treated districts. treated becomes 1 in the district’s adoption year. event_time is years since adoption and is missing for never-treated districts.

Both outcome columns describe the same continuous outcome: outcome_raw = 50 + 10 * outcome_std. We use raw score points for all models and graphs here. One reference SD equals 10 raw points. The scale is synthetic and unbounded, not a real test score or a 0-100 scale. Standardization uses the pooled untreated Years 1-4 reference distribution, not each cohort or year separately.

2. Traditional DID

In Simulation 1, 80 districts adopt in Year 5 and 80 remain untreated. The research question is: Do districts improve after adopting a gifted education program, compared with the change in districts that remain untreated?

Plot the observed group means first. Parallel trends concerns how the groups would change without treatment; similar observed pre-trends alone do not prove it.

simple_means <- simple |>
  mutate(group = ifelse(treated_ever == 1, "Adopts in Year 5", "Never treated")) |>
  group_by(group, year) |>
  summarise(mean_score = mean(outcome_raw), .groups = "drop")
ggplot(simple_means, aes(year, mean_score, color = group)) +
  geom_vline(xintercept = 4.5, linetype = 2, color = "grey55") +
  geom_line(linewidth = 0.9) + geom_point(size = 2) +
  scale_x_continuous(breaks = 1:7) +
  scale_color_manual(values = c("#2454a6", "#117c78")) +
  labs(x = "Study year", y = "Mean achievement (raw score points)", color = NULL) +
  theme_minimal(base_size = 13) + theme(legend.position = "bottom")

3. Estimate TWFE

District fixed effects account for stable differences across districts. Year fixed effects account for common year changes. The treated coefficient estimates the ATT under parallel trends, no anticipation, and the other DID assumptions. This simulation uses a constant treatment effect. Cluster standard errors by district because the same districts are observed repeatedly and treatment is assigned at the district level.

twfe <- feols(outcome_raw ~ treated | district_id + year,
              data = simple, vcov = ~district_id)
twfe_ci <- confint(twfe, "treated")
twfe_table <- data.frame(
  estimate = coef(twfe)["treated"], std_error = se(twfe)["treated"],
  lower_95 = twfe_ci[1, 1], upper_95 = twfe_ci[1, 2])
kable(twfe_table, digits = 3, row.names = FALSE)
estimate std_error lower_95 upper_95
2.287 0.345 1.606 2.968

The estimated effect is 2.29 raw score points, or 0.229 reference SDs. These are simulated results, not evidence about the effectiveness of gifted education.

With this balanced, common-start panel, TWFE equals the difference between group changes averaged over all pre- and all post-treatment years. Check that directly:

changes <- simple |>
  group_by(treated_ever) |>
  summarise(change = mean(outcome_raw[year >= 5]) - mean(outcome_raw[year < 5]))
manual_did <- changes$change[changes$treated_ever == 1] - changes$change[changes$treated_ever == 0]
stopifnot(abs(manual_did - coef(twfe)["treated"]) < 1e-8)
manual_did
#> [1] 2.287095

4. Staggered DID

Simulation 2 has 40 districts in each cohort: Year 5, Year 6, Year 7, and never treated. Effects vary across cohorts and with time since adoption. The earlier cohort contributes three post-treatment years, the next contributes two, and the last contributes one. A single TWFE coefficient can mix comparisons with already-treated groups when effects vary.

timing <- staggered |>
  distinct(cohort, treatment_start_year, year, treated)
ggplot(timing, aes(year, reorder(cohort, -treatment_start_year), fill = factor(treated))) +
  geom_tile(color = "white", width = 0.94, height = 0.75) +
  scale_x_continuous(breaks = 1:7, position = "top") +
  scale_fill_manual(values = c("#e1e7eb", "#2454a6"), labels = c("Untreated", "Treated")) +
  labs(x = "Study year", y = NULL, fill = NULL) +
  theme_minimal(base_size = 13) +
  theme(panel.grid = element_blank(), legend.position = "bottom")

5. Estimate Cohort-Period Effects

Callaway and Sant’Anna estimate an ATT for each cohort and post-treatment period. Here we use never-treated districts as controls. xformla = ~1 means no adjustment covariates. The baseline for a post-treatment effect is the year just before that cohort adopts. For example, ATT(5,7) compares the Year 4-to-7 change in the Year 5 cohort with that change in the never-treated group.

set.seed(20261014)
cs <- att_gt(
  yname = "outcome_raw", tname = "year", idname = "district_id",
  gname = "treatment_start_year", xformla = ~1, data = as.data.frame(staggered),
  panel = TRUE, control_group = "nevertreated", base_period = "universal",
  anticipation = 0, est_method = "reg", bstrap = TRUE, biters = 999,
  clustervars = "district_id", cband = TRUE
)
cells <- tibble(cohort = cs$group, year = cs$t, ATT = cs$att, SE = cs$se) |>
  filter(year >= cohort)
kable(cells, digits = 3)
cohort year ATT SE
5 5 1.322 0.414
5 6 2.720 0.587
5 7 3.768 0.654
6 6 1.805 0.524
6 7 1.482 0.596
7 7 1.778 0.559

The table shows post-treatment effects and bootstrap standard errors. The multiplier bootstrap clusters at district level. cband = TRUE requests simultaneous confidence bands in the package summary; individual estimate intervals and simultaneous bands answer different uncertainty questions.

6. Compute the Simple ATT

The Simple ATT averages the cohort-period effects with cohort-size weights. There are six observed post-treatment cells. All cohort sizes are 40, so each cell receives weight 1/6. Cohort 5 contributes 3/6 of the total weight, cohort 6 contributes 2/6, and cohort 7 contributes 1/6. This is not an equal-weight average of the three cohort averages.

simple_att <- aggte(cs, type = "simple")
cohort_sizes <- staggered |>
  distinct(district_id, treatment_start_year) |>
  count(treatment_start_year, name = "districts")
weighted_cells <- cells |>
  left_join(cohort_sizes, by = c("cohort" = "treatment_start_year")) |>
  mutate(weight = districts / sum(districts), contribution = weight * ATT)
kable(select(weighted_cells, cohort, year, districts, ATT, weight, contribution), digits = 3)

The Simple ATT is 2.15 raw score points. The calculation uses unrounded values. The package computes uncertainty using the joint estimation structure; do not average the six standard errors.

For a direct check of the six DID contrasts:

manual_cell <- function(g, t) {
  treated_change <- with(staggered, mean(outcome_raw[treatment_start_year == g & year == t]) -
                          mean(outcome_raw[treatment_start_year == g & year == g-1]))
  control_change <- with(staggered, mean(outcome_raw[treatment_start_year == 0 & year == t]) -
                          mean(outcome_raw[treatment_start_year == 0 & year == g-1]))
  treated_change - control_change
}
manual_effects <- mapply(manual_cell, cells$cohort, cells$year)
stopifnot(max(abs(manual_effects - cells$ATT)) < 1e-8)

7. Extended TWFE (Optional)

Extended TWFE allows cohort and time interactions rather than imposing one constant treatment coefficient. Use the same never-treated comparison group and raw outcome. emfx(type = "simple") summarizes post-treatment effects across treated observations. In this balanced panel, those observations give the same 1/6 weights to the six cells. Estimates can still differ because the estimation methods use time periods differently; matching the estimand does not guarantee identical finite-sample results.

extended <- etwfe(outcome_raw ~ 0, tvar = year, gvar = treatment_start_year,
                  data = staggered, cgroup = "never", gref = 0,
                  vcov = ~district_id)
extended_att <- emfx(extended, type = "simple")
kable(as.data.frame(extended_att)[, c("estimate", "std.error", "conf.low", "conf.high")], digits = 3)
estimate std.error conf.low conf.high
2.146 0.343 1.473 2.819

This optional model uses district-clustered covariance estimates and delta-method uncertainty, rather than the CSA multiplier bootstrap.

8. Event Study (Optional)

For Simulation 1, estimate separate coefficients relative to Year 4, the final pre-treatment year. Never-treated districts provide the comparison. Years 5, 6, and 7 correspond to event times 0, 1, and 2. Pre-treatment estimates are diagnostics, not proof of parallel trends. This common-start specification should not be carried over mechanically to staggered adoption.

event_model <- feols(outcome_raw ~ i(year, treated_ever, ref = 4) | district_id + year,
                     data = simple, vcov = ~district_id)
iplot(event_model, xlab = "Study year (Year 4 reference)",
      ylab = "Effect relative to Year 4 (raw points)",
      main = "Simulation 1: common-start event study")

The plot shows pointwise 95% confidence intervals. Multiple pre-period tests require care; failure to reject a pre-trend is not evidence that the identifying assumptions hold.
