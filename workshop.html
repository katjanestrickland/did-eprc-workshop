2. Load the Data

Both datasets contain 832 simulated districts representing Texas, each observed over seven years. Each row represents one district in one year. Both panels are balanced and treatment is assigned at the district level. The downloaded files contain only district_id, year, treatment_start_year, and outcome_std.

Place the downloaded CSV files in your R project folder

simple <- read_csv("simple_did_district.csv")
staggered <- read_csv("staggered_did_district.csv")

read_csv() comes from readr. Each row is one district in one year. We use outcome_std, measured in standard-deviation (SD) units. The outcome is standardized before treatment effects are added.

Create the Treatment Indicators

Our dataset records each district’s first treatment year in treatment_start_year. A value of 5 or 6 tells us when the district adopts the policy, while 0 means it never adopts. Panel data often provide adoption timing in this form, and we need to convert it into the indicators required for our models.

We create two variables

Variable Meaning Used in this lab
treated_ever 1 in every year for a district that eventually adopts, and 0 for a never-treated district The traditional DID event study
treated 1 from the district’s adoption year onward, and 0 otherwise The two-by-two DID and TWFE regressions

For a district that adopts in Year 5

Year treatment_start_year treated_ever treated
4 5 1 0
5 5 1 1
6 5 1 1

The distinction is between belonging to the treatment group and currently receiving treatment. For never-treated districts, both indicators equal 0 in every year.

The CSA function att_gt() uses treatment_start_year directly to identify adoption groups. It does not require either of these new indicators as an input.

We use mutate() from dplyr to create the variables in both datasets

simple <- simple %>%
  mutate(
    treated_ever = as.integer(treatment_start_year > 0),
    treated = as.integer(
      treatment_start_year > 0 & year >= treatment_start_year
    )
  )
staggered <- staggered %>%
  mutate(
    treated_ever = as.integer(treatment_start_year > 0),
    treated = as.integer(
      treatment_start_year > 0 & year >= treatment_start_year
    )
  )

The first condition identifies districts that eventually adopt. The second checks that the district adopts and that the observation is in its adoption year or later. as.integer() converts these conditions into 1s and 0s.

4. Estimate the Classic Two-by-Two DID

Use Year 4, immediately before adoption, and Year 5, the first treated year. We use the same equation as the slides

ATT̂2×2=(Y¯G,post−Y¯G,pre)−(Y¯C,post−Y¯C,pre) \widehat{\operatorname{ATT}}_{2\times2} =(\overline Y_{G,\mathrm{post}}-\overline Y_{G,\mathrm{pre}}) -(\overline Y_{C,\mathrm{post}}-\overline Y_{C,\mathrm{pre}})

GG is the treated group, CC the control group, and Y¯\overline Y a group mean. Under parallel trends and no anticipation, the control change supplies the untreated change for the treated group. Estimate the contrast using the slides’ TWFE equation

Yit=αi+λt+βDit+uit Y_{it}=\alpha_i+\lambda_t+\beta D_{it}+u_{it} 
two_period <- simple %>%
  filter(year %in% c(4, 5))
model_2x2 <- feols(
  outcome_std ~ treated | district_id + year,
  data = two_period,
  vcov = ~ district_id
)
summary(model_2x2)

Only data = simple changes. We now use all seven years. District effects account for persistent differences. Year effects account for common shocks. In this balanced common-adoption design, the coefficient equals the treated group’s average pre-to-post change minus the control group’s average change. We added a treatment effect of 0.20 SD in each post-treatment year. The model estimates one coefficient summarizing that effect across Years 5-7. The time-constant treated_ever variable would be absorbed by district effects. Use treated, which switches on at adoption.

6. Estimate an Event Study

We use the same equation as the slides

Yit=αi+λt+∑k≠−1βk𝟏{t−g=k}+uit Y_{it}=\alpha_i+\lambda_t+ \sum_{k\neq-1}\beta_k\,\mathbf{1}\{t-g=k\}+u_{it}

Treatment begins in Year 5, so g=5g=5 and event time is the study year minus 5, k=t−gk=t-g. The model compares treated and never-treated districts in each year, using Year 4 as the reference year.

Study year Event time Interpretation
1, 2, 3 -4, -3, -2 Pre-treatment comparisons
4 -1 Reference period
5, 6, 7 0, 1, 2 First, second, third treated year 
simple <- simple %>%
  mutate(relative_year = year - 5)
model_event <- feols(
  outcome_std ~ i(relative_year, treated_ever, ref = -1) |
    district_id + year,
  data = simple,
  vcov = ~ district_id
)
summary(model_event)

mutate() is from dplyr. This relative-year index is defined for every observation. Never-treated districts have no adoption year of their own, so we use the common Year 5 reference for this index and distinguish the treated group with treated_ever. i(relative_year, treated_ever, ref = -1) from fixest creates a separate comparison for each year. Multiplying the year indicators by treated_ever distinguishes treated districts from never-treated districts. Setting ref = -1 makes the year before treatment the reference period.

Each βk\beta_k measures how the treated-control gap differs from its Year 4 value. Pre-treatment coefficients are diagnostics, not proof of parallel trends. Under parallel trends and no anticipation, post-treatment coefficients estimate effects relative to Year 4. We added an effect of 0.20 SD in each of Years 5-7. The three post-treatment coefficients estimate those effects separately.

This example has one treatment start year. In the staggered example, districts begin treatment in different years, so we next estimate effects separately for each adoption cohort and study year.

7. Move to Staggered Adoption

Effects now depend on cohort and year

ATT⁡(g,t)=𝔼[Yit(g)−Yit(0)∣i∈Gg],t≥g \operatorname{ATT}(g,t)=\mathbb{E}[Y_{it}(g)-Y_{it}(0)\mid i\in G_g], \qquad t\geq g

GgG_g is the cohort first treated in gg. Yit(g)Y_{it}(g) is the potential outcome when treatment starts in gg. Yit(0)Y_{it}(0) is the outcome without treatment.

Cohort gg Year tt True effect (SD)
5 5 0.10
5 6 0.20
5 7 0.30
6 6 0.15
6 7 0.25

These schedules are known effects added to the simulated untreated outcomes. A single TWFE coefficient can mix never-treated, not-yet-treated, and already-treated comparisons. Already-treated controls can be problematic when effects change over time.

8. Estimate Group-by-Time ATTs

Use att_gt() from did, implementing Callaway and Sant’Anna (2021). We compare each cohort with never-treated districts

ATT̂(g,t)=(Y¯g,t−Y¯g,g−1)−(Y¯C,t−Y¯C,g−1) \widehat{\operatorname{ATT}}(g,t) =(\overline Y_{g,t}-\overline Y_{g,g-1}) -(\overline Y_{C,t}-\overline Y_{C,g-1})

ATT(6,7) compares the Year 6 cohort’s change from Year 5 to Year 7 with the control group’s change over those same years.

set.seed(20261014)

9. Read the Estimates and Uncertainty

Group identifies adoption cohort and Time identifies outcome year. Group 5 and Time 7 identify ATT(5,7), whose true value is 0.30 SD. Pre-treatment comparisons are diagnostics, not effects of an already-active treatment.

bstrap = TRUE uses a multiplier bootstrap. biters = 1000 selects 1,000 iterations. clustervars = “district_id” allows within-district dependence over time. set.seed() makes the bootstrap reproducible in the same computing setup.

cband = TRUE requests simultaneous confidence bands across group-by-time estimates, rather than separate pointwise intervals. See the did inference options.

10. Estimate Group Averages

A group average summarizes a group’s effects across its post-treatment years.

ATT̂group(g)=1T−g+1∑t=gTATT̂(g,t) \widehat{\operatorname{ATT}}_{\mathrm{group}}(g) =\frac{1}{T-g+1}\sum_{t=g}^{T}\widehat{\operatorname{ATT}}(g,t)

Here T=7T=7. The early group contributes Years 5-7 and the late group Years 6-7. Their known averages are (0.10+0.20+0.30)/3=0.20(0.10+0.20+0.30)/3=0.20 SD and (0.15+0.25)/2=0.20(0.15+0.25)/2=0.20 SD.

group_att <- aggte(model_csa, type = "group")
summary(group_att)

aggte() from did takes the model returned by att_gt(). type = “group” averages within each adoption group. Read the group-specific rows for each group’s average. The overall summary additionally averages the group averages using group-size weights. It is not the same weighting rule as Simple ATT, even though their true values coincide here.

11. Estimate Calendar Summaries

A calendar summary averages effects across groups already treated in the same study year.

ATT̂calendar(t)=∑g≤tNg∑h≤tNhATT̂(g,t) \widehat{\operatorname{ATT}}_{\mathrm{calendar}}(t) =\sum_{g\le t}\frac{N_g}{\sum_{h\le t}N_h} \widehat{\operatorname{ATT}}(g,t)

NgN_g is the number of districts in treated cohort gg. The sums are over treated cohorts. Only early adopters contribute in Year 5. Both groups contribute in Years 6 and 7.

5 0.10
6 (0.20 + 0.15) / 2 = 0.175
7 (0.30 + 0.25) / 2 = 0.275

12. Estimate Simple ATT

Following the slides, we calculate the Simple ATT

ATT̂simple=∑g∑t=gTwg,tATT̂(g,t),wg,t=Ng∑hNh(T−h+1) \widehat{\operatorname{ATT}}_{\mathrm{simple}} =\sum_g\sum_{t=g}^{T}w_{g,t}\widehat{\operatorname{ATT}}(g,t), \qquad w_{g,t}=\frac{N_g}{\sum_h N_h(T-h+1)}

NgN_g is cohort size and T=7T=7 is the final year. This formula applies to our balanced panel without sampling weights. The treated cohorts have equal size, so each of the five cells receives weight 1/5. The true summary is

ATT⁡simple=0.10+0.20+0.30+0.15+0.255=0.20 \operatorname{ATT}_{\mathrm{simple}} =\frac{0.10+0.20+0.30+0.15+0.25}{5}=0.20

aggte() from did takes the fitted model_csa object, not the original dataset. type = “simple” selects the aggregation rule. The early cohort contributes three post-treatment years and the late cohort two, giving total weights 3/5 and 2/5. Never-treated districts supply the comparison, but receive no treatment-effect weight. Do not average the five standard errors. The package accounts for joint uncertainty.
