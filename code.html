Workshop Code

Run the complete lab in R or RStudio, or follow the guided Workshop page. The examples use the October 14 seven-year datasets and no adjustment covariates.

File Contents
Complete R script Import, descriptive statistics, plots, TWFE, CSA, manual Simple ATT, and optional extended TWFE and event study.
R Markdown source The explanations and executable code that produce the Workshop page.

Install the packages before the session. The script loads local CSV files when present and otherwise downloads them from this website. All models and plots use outcome_raw; standard errors account for clustering by district.

The optional extended-TWFE and event-study sections can be explored after the 30-minute lab. The page includes the R/package versions used for the displayed results.
