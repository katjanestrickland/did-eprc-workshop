Workshop Code

Use the Texas-calibrated datasets from the Data page with the Hands-on R Lab. All models use standard-deviation units and district-level inference.

File Purpose
Lab R script Local CSV imports, two-by-two DID, TWFE, event study, cohort-time effects, and Simple ATT.
R Markdown source Explanations and executable code for the Workshop page.
Data-generation R script Generate the two Texas-calibrated teaching datasets and instructor validation files.
Texas calibration inputs State-specific inputs extracted from the original simulation parameter file; needed only to regenerate data.

Run the Lab

Install R and the packages before the session. Place both dataset CSVs in your R project folder, then run the lab script. No plotting packages are needed. ETWFE remains a lecture-only extension.

Regenerate the Data

Put the generator in a folder named code and the calibration CSV in a sibling folder named data. Install dplyr, readr, and haven, then run the script with Rscript. It writes the teaching CSV and Stata files to data, and the known effects and untreated outcomes to validation. Seed 20261014 reproduces the datasets in the same R environment.
